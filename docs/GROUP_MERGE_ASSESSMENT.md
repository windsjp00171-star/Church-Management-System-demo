# 評估：把「標籤小組」和「週間小組」合成一份（2026-11-17）

> 起因：使用者說「在我的認知裡他是同一個小組」。系統現在把同一群人存成兩份互不相認的名單。
> 這份只是評估，**還沒有動任何程式或資料**；下面「要你決定的」三件事定了才開始。

## 〇、補充（2026-11-17 查到的）
後台「服事團隊」（`/admin/groups`，頁面標題「服事標籤管理」）**只能新增副標籤**（敬拜團、招待…）——
新增時寫死 `is_primary=False`，頁面上也寫「週間小組的分組管理請前往牧養小組管理」。
也就是說，**系統早就把「小組」定在週間小組（牧養小組）**，主標籤小組只剩以前留下來的資料，已經沒有地方新增。
所以合併的方向其實已經決定了：以週間小組為準，標籤只留服事角色。

## 一、現在的樣子（查過程式碼，不是推測）

| | 標籤小組 `groups`（主標籤 `is_primary=true`） | 週間小組 `cell_groups` |
|---|---|---|
| 在哪設定 | 後台「小組（標籤）管理」 | 後台「小組回報管理」 |
| 有什麼欄位 | 名稱、排序、是否主標籤、是否同工組、權限（副標籤用） | 名稱、組長姓名、聚會日、是否兒童小組 |
| **誰屬於哪一組** | 會友帳號上的 `users.group_tags`（**存的是組名文字**，不是編號）；會友自己在個人資料勾 | `cell_members`（**姓名**，可連帳號 `user_id`，要管理員確認）；組長 `cell_group_leaders` |
| 沒有帳號的人 | 放不進來 | 放得進來（只有姓名） |
| 誰在用 | 個人資料、收款／禱讀本依組、課程分組、檔案權限、同工判斷（`is_staff`）、**副標籤＝後台權限矩陣** | 小組回報（出席、週報）、讀經進度分組、點名單分段（023 起）、課程、組長判斷 |
| 用到的程式 | `groups` 7 支、`group_tags` 約 100 處（含 13 個模板） | 約 70 處，13 支程式 |

另外還有第三種「群組」：`user_groups`／`group_members`（檔案分享與後台用的自訂名單），跟小組無關，**這次不碰**。

### 兩份分開造成的問題（都是「畫面看起來正常」的那一類）
1. 同一個人可能在標籤是「週二小組」、在小組回報卻在「週四小組」——兩邊各自看都對，沒有地方會紅。
2. 改組名：`group_tags` 存的是**文字**，在標籤那邊改名，會友帳號上的舊名不會跟著改（這是既有的另一個洞，合併時一起處理）。
3. 新的小組要在兩個後台各建一次；漏建一邊，那個功能就看不到這一組。

## 二、建議做法：分三步，每一步都能單獨停下來

**不建議**一次把兩張表合成一張：要改約 170 處、搬正式站的資料，而副標籤（權限）也住在 `groups` 裡——拆錯一刀就是有人突然進不了後台、或多看到不該看的。

### 第 1 步：對照表（零風險，不改資料）—— ✅ 已做（2026-11-17，後台「小組對照」`/admin/groups/compare`）
後台多一頁「小組對照」：列出兩邊的組名、**兩邊都有／只有一邊有**、以及「標籤寫 A 組、小組回報卻在 B 組」的人。
目的：先知道正式站實際上分歧到什麼程度，再決定第 2 步怎麼做。**不用改資料庫。**

### 第 2 步：把兩邊「配對」起來（要 SQL，一欄）
```sql
ALTER TABLE groups ADD COLUMN IF NOT EXISTS cell_group_id UUID REFERENCES cell_groups(id) ON DELETE SET NULL;
```
- 管理員在對照頁把「標籤的週二小組」和「週間的週二小組」**手動配對**（同名的系統會預先建議，但要人按確認——不自動猜）。
- 配對後：新增／改名只在一邊做，另一邊跟著（例如以週間小組為主，標籤自動同名）。
- 回復：`ALTER TABLE groups DROP COLUMN cell_group_id;`（只拿掉配對，兩邊資料都不受影響）

### 第 3 步：「誰屬於哪一組」只留一份
配對完成後，讓其中一邊變成另一邊**算出來的**，不再各存各的。這一步才是真正的合併，要看第 1 步的結果再細談。

## 三、要你決定的（定了我才開始第 1 步以外的事）

1. **「這個人是哪一組」以誰為準？**
   - (a) **小組回報那邊**（組長在維護、可以放沒有帳號的人）——我傾向這個，因為組長最清楚自己組裡有誰。
   - (b) 會友自己在個人資料選的標籤。
2. **主標籤小組是不是全部都是週間小組？** 如果主標籤裡有「青年牧區」「同工團隊」這種不是週間小組的分類，它們要留在標籤、不參與合併。
3. **兒童小組**（週間小組裡有標記）要不要也對應到標籤？

## 四、不在這次範圍
- 副標籤（後台權限矩陣）**完全不動**——它跟「小組」只是剛好住在同一張表。
- 正式站資料我看不到，所有分歧的數字要等第 1 步的對照頁上線後在你的站上看。
