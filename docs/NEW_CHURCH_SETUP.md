# 新教會部署與交接手冊（給非技術同工）

> 這份文件假設你**不會寫程式**。照順序做，做不下去就停在那一步，把畫面截圖給維護的人。
> 標「（未驗證）」的畫面，是依官方文件寫的，我沒有在你的帳號上實際點過。

## 這個系統是什麼、誰負責什麼
- **教會**擁有並持有這幾個帳號：Supabase（資料庫）、Render（網站主機）、LINE Developers（登入）。**維護的人不保管你的密碼與金鑰。**
- **維護的人**負責：更新程式、提供資料庫腳本、現場協助第一次部署。維護的人**不會**看你們會友的資料。
- **教會超級管理員**（牧師或行政）負責：決定要開哪些功能、會友與權限管理、定期備份。

## 一、部署前要準備（用教會的 email 註冊，自己設密碼）
1. **Supabase** 新 Project，區域選 Singapore。
2. **Render** 帳號。
3. **LINE Developers**：建立 Provider 與「LINE Login」頻道。
4. （若要檔案分享）**Cloudflare R2**。
5. 兩個人各自保管一份金鑰備份（見第六節）。

## 二、資料庫（Supabase）
1. 進入你的 Project → 左邊 **SQL Editor**。
2. 把維護的人給你的 `schema.sql` **整份貼上**，按 Run。可以重複執行，不會壞。
3. 到 **Project Settings → API Keys**，複製「**服務端金鑰**」（`service_role` 或 `secret`，名稱可能略有不同）。
   - 這把金鑰**只貼進 Render 的環境變數**，不要貼進聊天、信件或任何文件。
   - **不要**用「公開金鑰」（`anon`／`publishable`）。
   - 完整原因見 `docs/SUPABASE_SETUP.md`。

## 三、網站（Render）與登入（LINE）
1. 照 Render 的畫面建立 Web Service（維護的人會現場帶你）。
2. 環境變數填入：`SUPABASE_URL`、`SUPABASE_KEY`（上面的服務端金鑰）、`FLASK_SECRET_KEY`、`LINE_CHANNEL_ID`、`LINE_CHANNEL_SECRET`、`LINE_REDIRECT_URI`、`CHURCH_NAME`、`CHURCH_SHORT_NAME`。
3. **`DEMO_MODE` 一定要是 false 或不要設定**（它只給展示站用，會顯示洽詢橫幅與展示帳號）。
4. 部署精靈 `/setup-wizard` 會告訴你還缺哪些設定（超管登入後才看得到）。

## 四、第一位超級管理員
1. 教會的主責行政**自己用 LINE 登入一次**。
2. 照部署精靈第 4 步的說明，把這個帳號設成超級管理員。
3. **維護的人不持有超級管理員身分。**

## 五、選擇這間教會要用的功能
1. 超管登入 → 後台 → **選用功能模組**（`/admin/modules`）。
2. 勾選要用的功能，按儲存，約半分鐘內全站生效。
3. **關掉的功能會整塊消失**（網址、首頁卡片、後台入口），**但資料不會刪**，之後隨時可以再打開。
4. 有些功能需要額外設定：檔案分享需要 R2；天父日記的 AI 反思引導需要 AI 金鑰（可選）。
5. 人、登入、權限、稽核、通知、備份是核心，永遠開著。
6. 再到 **權限矩陣**（`/admin/permissions`）決定哪個服事身份（副標籤）能進哪些後台功能。

## 六、備份與交接（請務必做）
- **每月**到後台 **資料備份中心** 下載一次（CSV、ZIP 或 HTML 離線閱讀器）。HTML 離線閱讀器**不需要網路、不需要帳號**，雙擊就能看資料。
- **金鑰兩個人各保管一份**（例如牧師與行政），不要放在同一個地方。遺失或外洩時，到 Supabase／LINE 後台**重新產生金鑰**，更新 Render 環境變數後重新部署。
- **還原演練**：目前系統還沒有一鍵還原的功能（資料可以匯出、也可以匯入，但完整的「在空白專案上還原一次」演練尚未做過）。建議在第一次正式使用前，請維護的人陪你做一次。（未驗證）

## 七、免費方案的限制（要知道，不是故障）
- **Supabase 免費版**：一週沒有任何使用，專案會被暫停，需要自己到後台按「恢復」。
- **Render 免費版**：一段時間沒人用會休眠，第一次打開會慢 30 秒左右。
- 這些是第三方平台的限制，不是系統壞掉；要避免就需要升級付費方案。

## 八、出問題時
1. 先看網站打不打得開、Supabase 有沒有被暫停。
2. 部署精靈 `/setup-wizard` 會顯示哪個設定缺了。
3. 把畫面截圖與時間給維護的人。**不要把金鑰貼進對話。**
